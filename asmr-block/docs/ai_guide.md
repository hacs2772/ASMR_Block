# AI 조합 켜기 — 오늘 밤 조합의 "한 줄로 말하면 쌓아 줘요"

홈의 **오늘 밤 조합**에 "비 오는 날 카페에서 책 읽는 느낌"처럼 한 줄을 적으면,
**AI(Claude)가 그 말을 읽고** 어떤 트리거를 얼마나 넣을지 정해요 (예: 바스락 75% · 탭핑 25% + 둘째 줄 빗소리).
실제로 블록을 고르고 두 줄로 쌓는 건 늘 서버 규칙이 해요 → AI가 엉뚱한 말을 해도 없는 블록이 들어가거나 겹칠 일이 없어요.

- **키가 없어도 다 돼요.** 키가 없으면 한 줄에서 낱말(비·카페·책·모닥불·귓속말…)을 찾아서 쌓고, 한 줄 없이 "내 취향대로 쌓기"도 돼요.
- 키를 넣으면 홈 카드에 **AI** 표시가 생기고, 낱말이 없는 말("오늘 너무 지쳤어, 포근하게")도 알아들어요.

## 얼마나 드나요?

모델은 **Claude Haiku 5.5** (가장 싸고 빠른 모델)를 써요. 요금은 100만 토큰당 입력 $0.10 · 출력 $0.50.

| | 대략 |
|---|---|
| 한 번 만들 때 | 입력 600~1,000토큰 + 출력 100~300토큰 → **약 0.3~1원** |
| 하루 100번 × 30일 | **약 1천 원 안팎** |

실제로 쓴 횟수와 대략 요금은 **관리자 페이지 → 통계** 맨 위 "AI 조합" 줄에 나와요 (이번 달 몇 번 · 대략 몇 달러/원).
요금은 바뀔 수 있으니 정확한 값은 Claude 콘솔의 요금 화면에서 확인해 주세요.

## 켜는 법 (돈 관련이라 직접 해 주세요)

1. **Claude 콘솔 가입**: <https://platform.claude.com> (예전 주소 console.anthropic.com). Claude 앱 구독과는 따로예요.
2. **결제 등록 + 충전**: Billing(결제)에서 카드를 등록하고 크레딧을 조금(예: $5) 충전해요.
3. **⚠ 한 달 사용 한도 정하기**: Limits(사용 한도)에서 한 달 한도를 예를 들어 $5로. 한도를 넘으면 Claude가 멈추고,
   우리 서버는 저절로 "낱말로 찾기"로 바꿔서 조합은 계속 만들어져요.
4. **API 키 만들기**: API Keys → Create Key → 이름 `asmrblock` → 나온 키(`sk-ant-`로 시작)를 복사. **한 번만 보여요.**
5. 공개 서버 PC(지금은 회사 PC)의 `asmr-block/.env.public` 맨 아래에 한 줄 넣기:
   ```
   ANTHROPIC_API_KEY=sk-ant-여기에-복사한-키
   ```
6. `start-public.bat` 다시 실행(재시작).
7. 확인: asmrblock.com 홈의 오늘 밤 조합에 **AI** 표시 · 관리자 페이지 통계에 **"AI 조합 켜짐 (claude-haiku-5-5)"**.

⚠ 키는 `.env.public`에만 넣어 주세요 (이 파일은 저장소에 안 올라가요). 카톡·메일·채팅에 붙여 넣지 마세요.
혹시 새어 나갔으면 콘솔 API Keys에서 그 키를 지우고(Delete) 새로 만들어 넣으면 돼요.

## 안전장치 (요금이 갑자기 늘지 않게)

- **한 사람 하루 10번**, **사이트 전체 하루 1,000번**(한국 시간)까지만 AI를 불러요. 넘으면 AI 없이 낱말로 쌓고 "오늘 AI 횟수를 다 써서…"라고 알려 줘요.
- 한 사람이 오늘 밤 조합을 **1시간에 30번** 넘게 만들면 잠깐 막아요 (429).
- AI가 대답을 못 하거나(오류·거절·엉뚱한 대답) 20초 안에 안 오면 → 낱말로 쌓아요. 조합은 늘 나와요.
- AI에게는 **적은 한 줄만** 보내요. 이메일·닉네임 같은 계정 정보는 안 보내요.
- 서버에는 부른 횟수·토큰 수만 남기고(`ai_usage` 표), 적은 문장은 그 조합의 설명으로만 남아요.
- 개인정보 처리방침의 "맡기는 곳"에 Anthropic(미국)을 넣어 뒀어요.

## 바꾸기·끄기

`.env.public`에 아래 줄을 넣고 `start-public.bat` 재시작:

| 하고 싶은 것 | 넣을 줄 |
|---|---|
| 한 사람 하루 횟수 줄이기 | `AI_DAILY_PER_USER=5` |
| 사이트 전체 하루 횟수 줄이기 | `AI_DAILY_TOTAL=300` |
| 더 똑똑한 모델 (약 20배 비쌈) | `AI_MODEL=claude-sonnet-5-5` |
| AI 끄기 | `ANTHROPIC_API_KEY=` 줄을 지우거나 맨 앞에 `#` |

## 개발자용 메모

- 서버: `tonight` 패키지 — `ClaudePlanner`(Anthropic Java SDK, 구조화된 JSON 대답·effort low), `WordPlanner`(낱말 표 `resources/tonight/words.tsv`),
  `TonightBuilder`(두 줄 쌓기 규칙), `TonightService`(AI → 낱말 → 취향 → 기본 순서), `AiUsageService`(V17 `ai_usage`, 하루 제한·요금).
- 설정: `application.yml`의 `app.ai.*` (키 `ANTHROPIC_API_KEY`, 모델 `APP_AI_MODEL`, 하루 횟수 `APP_AI_DAILY_PER_USER`·`APP_AI_DAILY_TOTAL`).
- 테스트는 진짜 API 대신 가짜 Claude 서버(`support/FakeClaudeServer`)로 → 요금 0원 (`TonightAiApiTest`).
