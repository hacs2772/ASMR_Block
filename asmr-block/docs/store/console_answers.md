# 스토어 심사 질문 답안 (구글 플레이 콘솔 · 앱스토어 커넥트)

지금 앱(코인 충전·광고 없음, AI는 키를 넣었을 때만)을 기준으로 적었어요.
**광고(AdMob)나 코인 충전(인앱결제)을 붙이면 ★ 표시한 칸을 꼭 다시 고쳐야 해요.**
애매한 칸은 "왜 이렇게 답했는지"를 같이 적었어요. 최종 선택은 사장님이 해 주세요.

---

## 구글 플레이 콘솔

### 1. 앱 액세스 (심사하는 사람이 들어갈 방법)
- **"일부 기능이 제한됨"** 선택 → 안내 추가
- 심사용 계정을 공개 서버에서 하나 만들어 적어 주세요 (예: `review@asmrblock.com` / 따로 정한 비밀번호)
  - 만드는 법: asmrblock.com → 가입 → 블록 상점에서 무료 블록 몇 개 담기 → 조합 하나 만들어 두기
- 안내 글 예시:
  ```
  1. 오른쪽 위 내 정보(또는 홈의 "로그인")에서 위 이메일·비밀번호로 로그인하세요.
  2. 홈 맨 위 조합의 재생 버튼을 누르면 바로 들을 수 있어요.
  3. "블록 편집" 탭에서 블록을 끌어 조합을 만들 수 있어요.
  Log in with the account above. Press play on the first combo on Home to listen. Build combos in the "Build" tab.
  ```

### 2. 광고 ★
- **"아니요, 광고가 없습니다"** (홈의 "광고" 자리는 지금 우리 안내 카드만 보여요. AdMob을 붙이면 "예"로)

### 3. 콘텐츠 등급 (IARC 설문)
- 카테고리: **"기타 앱 유형"**(게임·SNS 아님)
- 폭력·성적 내용·욕설·약물·도박: 모두 **아니요**
- **사용자가 만든 콘텐츠를 다른 사람과 나누나요? → 예**
  - 크리에이터가 올린 소리·사진·짧은 영상과 공개 조합을 다른 사람이 볼 수 있어요
  - 막는 방법(물어보면): 올린 블록은 관리자 확인 뒤에만 공개 · 블록/조합/사람 신고 · 관리자 숨기기·업로드 막기 · 이용약관에 금지 내용
- 사용자끼리 대화(채팅)·위치 공유: **아니요** ("녹음한 곳"은 크리에이터가 직접 적는 글이라 기기 위치가 아님)
- 디지털 상품 구매 ★: 지금은 **아니요** (코인 충전이 열리면 "예")
- 예상 등급: 모든 연령~12세 이상 정도 (설문 결과에 따름)

### 4. 타겟층과 콘텐츠
- 대상 연령: **16~17세, 18세 이상** 추천
  - 이유: 13세 미만을 고르면 "가족 정책"(광고·데이터 규칙이 훨씬 엄격)이 적용돼요. 약관상 만 14세 미만은 가입할 수 없어서 13~15세를 빼는 게 깔끔해요
- "어린이에게 흥미를 끄는 앱인가요?" → **아니요**

### 5. 데이터 보안 (Data safety)
- 데이터를 모으거나 나누나요? → **예, 모아요**
- 모든 데이터는 **전송 중 암호화**(https) → **예**
- 사용자가 데이터 삭제를 요청할 수 있나요? → **예** — 앱 "회원 탈퇴" + 웹 주소 `https://asmrblock.com/delete-account`
- 다른 회사와 **공유**: **없음**
  - 이유: Cloudflare(연결), Anthropic(AI가 켜졌을 때 오늘 밤 조합 한 줄)은 우리를 대신해 처리하는 곳이라 구글 기준 "공유"가 아니에요. 그래도 개인정보 처리방침에는 적어 뒀어요

| 데이터 종류 (콘솔 이름) | 모음 | 필수? | 쓰는 곳 |
|---|---|---|---|
| 개인 정보 › 이메일 주소 | 예 | 필수 | 계정 관리 |
| 개인 정보 › 이름 (닉네임) | 예 | 필수 | 앱 기능 (블록·조합에 @닉네임) |
| 사진 및 동영상 › 사진 · 동영상 | 예 | 선택 (크리에이터만) | 앱 기능 (블록 겉면·같이 보는 영상) |
| 오디오 › 음성 또는 소리 녹음 | 예 | 선택 (크리에이터만) | 앱 기능 (블록 소리) |
| 앱 활동 › 앱 상호작용 | 예 | 필수 | 앱 기능 · 분석 · 맞춤 추천 (재생 기록·담은 블록·조합) |
| 앱 활동 › 기타 사용자 제작 콘텐츠 | 예 | 선택 | 앱 기능 (조합 이름·한 줄·의견·신고 글) |
| 건강 및 피트니스 › 건강 정보 | 예 | 선택 | 맞춤 추천 ("어젯밤 잘 잤어요?" 답) |
| 금융 정보 › 구매 기록 ★ | 예 | 선택 | 앱 기능 (코인으로 산 블록) |

- 잠 기록은 "잘 잤어요/그저 그래요/못 잤어요" 한 번 누르는 것뿐이지만, 잠에 관한 정보라 **건강 정보로 적는 쪽이 안전**해요 (적지 않았다가 심사에서 지적받는 것보다 나아요)
- 접속 주소(IP)·기기 ID·위치·연락처·결제 카드: **모으지 않음** (IP는 잠깐 쓰고 남기지 않아요)
- 오류 기록·충돌 보고(Crashlytics 등): **없음**

### 6. 포그라운드 서비스 (안드로이드 14 이상)
- 앱이 **"미디어 재생"(FOREGROUND_SERVICE_MEDIA_PLAYBACK)** 을 써요 — 화면을 꺼도 소리가 계속 나오게
- 콘솔 "앱 콘텐츠 › 포그라운드 서비스 권한"에서 **미디어 재생**을 고르고 설명:
  ```
  사용자가 고른 ASMR 조합을 화면을 끈 뒤에도 계속 재생하고, 알림·잠금화면에서 멈춤/재생할 수 있게 합니다.
  Keeps playing the ASMR mix the user started after the screen turns off, with play/pause in the notification and lock screen.
  ```
- **짧은 영상**(유튜브 일부 공개 링크 등)이 필요해요: 조합 재생 → 화면 끄기 → 소리가 계속 남 → 잠금화면에서 멈춤, 20~30초면 충분

### 7. 권한
- 앱이 요청하는 권한: 사진 고르기(크리에이터가 겉면 사진·영상을 고를 때만, 안드로이드 사진 선택기)
- 막아 둔 권한(앱에 안 들어감): 마이크, 카메라, 다른 앱 위에 그리기 — 그래서 "카메라를 왜 쓰나요?" 같은 질문은 없어요

### 8. 기타
- 정부 앱·금융 앱·건강 앱(의료) 여부: 모두 **아니요**
- 뉴스 앱: **아니요**
- 개인정보 처리방침 주소: `https://asmrblock.com/privacy`
- 고객 지원 이메일: `help@asmrblock.com` · 웹사이트: `https://asmrblock.com`
- 카테고리: **음악 및 오디오** 추천 (건강/운동으로 하면 건강 효과를 묻는 심사가 더 까다로울 수 있어요)

## 앱스토어 커넥트 (아이폰은 애플 개발자 계정을 만든 뒤)

### 앱 개인정보 보호 ("영양 성분표")
- 추적(Tracking, 다른 회사 앱·웹과 묶어 광고에 쓰기): **안 함**
- "나와 연결된 데이터"로 적을 것:
  - 연락처 정보 › 이메일 주소 — 앱 기능
  - 사용자 콘텐츠 › 사진 또는 비디오 · 오디오 데이터 · 기타 사용자 콘텐츠 — 앱 기능
  - 사용 데이터 › 제품 상호작용 — 앱 기능 · 분석 · 맞춤화
  - 건강 및 피트니스 › 건강 — 맞춤화 (잠 기록)
  - 구입 항목 › 구입 내역 ★ — 앱 기능
- 식별자·위치·연락처·검색 기록·진단: **수집 안 함**

### 심사 메모 (App Review Information)
```
Demo account: (위 심사용 계정)
- Press play on the first combo on Home to listen. Audio keeps playing in the background (sleep sounds).
- User-generated content: blocks are reviewed by an admin before they appear; users can report any block, combo or creator, and admins can hide content and ban uploads.
- Account deletion: My account → "Delete account" (also https://asmrblock.com/delete-account).
- Coins in this build can only be granted by the admin for the beta; there is no real-money purchase yet.
```
- ⚠ **코인으로 유료 블록을 여는 기능**: 애플은 디지털 콘텐츠를 돈으로 팔면 **반드시 인앱결제**여야 해요. 지금처럼 코인을 "받기"만 하는 건 괜찮지만, 심사에서 물어볼 수 있어요. 충전이 열리면 인앱결제로 해야 해요
- 사용자 콘텐츠 앱 규칙(1.2): 신고 ✓ · 관리자 확인 ✓ · 숨기기·업로드 막기 ✓ · 연락처(help@) ✓. 혹시 "사용자 차단"을 요구하면 "이 크리에이터 숨기기"를 더 만들면 돼요
- 로그인: 이메일만 써서 "Apple로 로그인"은 필요 없어요 (구글·카카오 로그인을 붙이면 같이 넣어야 해요)
- 암호화 질문: `app.json`에 `usesNonExemptEncryption: false`를 넣어서 빌드마다 묻지 않아요 (https만 써요)
- 아이패드: `supportsTablet: false` — 아이폰 앱으로만 올려서 **아이패드 화면 사진이 필요 없어요** (아이패드에서도 아이폰 크기로 열려요)
