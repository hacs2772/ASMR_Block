# 파일을 클라우드(Cloudflare R2)로 옮기기

> 최종 수정일: 2026-11-16
> 지금은 올린 소리·사진·영상·완성본이 **회사 PC 디스크**에 있어요. PC가 고장 나면 위험하고, 사람이 많아지면 PC 인터넷이 느려져요.
> 서버는 이미 준비돼 있어서, **아래 키 6줄만 넣고 재시작**하면 클라우드로 바뀌어요. 옛 파일도 저절로 옮겨져요.

## 얼마나 드나요

| 항목 | 무료 범위 (매달) | 넘으면 |
|------|------|------|
| 저장 | 10GB | GB당 약 20원 ($0.015) |
| 사람들이 받아 가는 양(트래픽) | **무제한 무료** | — |
| 올리기·지우기 횟수 | 100만 번 | 100만 번당 약 6,000원 |
| 읽기 횟수 | 1,000만 번 | 1,000만 번당 약 500원 |

베타 동안은 거의 확실히 **0원**이에요. 다만 R2를 처음 켤 때 카드 등록을 요구할 수 있어요(무료 범위 안이면 청구 안 됨).

## 1. 버킷 만들기 (5분)

1. [Cloudflare 대시보드](https://dash.cloudflare.com) → 왼쪽 **R2 Object Storage** (처음이면 "R2 구독" → 무료 플랜)
2. **버킷 만들기** → 이름 `asmrblock-files` → 위치 "자동" → 만들기
3. 만든 버킷 → **설정** → **공개 액세스(Public access)** → **사용자 지정 도메인 연결** → `files.asmrblock.com` 입력 → 연결
   - asmrblock.com이 이미 Cloudflare에 있어서 바로 돼요 (몇 분 뒤 "활성")
   - 이 주소로 앱·웹이 소리를 받아요. 전 세계 Cloudflare 캐시를 거쳐서 빨라요

## 2. 키 만들기 (3분)

1. R2 첫 화면 → 오른쪽 **API 토큰 관리** (Manage R2 API Tokens) → **API 토큰 만들기**
2. 권한: **개체 읽기 및 쓰기** (Object Read & Write), 버킷: **asmrblock-files 만** → 만들기
3. 나오는 값 3개를 메모장에 복사 (이 화면을 닫으면 비밀 키는 다시 못 봐요)
   - **액세스 키 ID** (Access Key ID)
   - **비밀 액세스 키** (Secret Access Key)
   - **S3 클라이언트용 엔드포인트**: `https://계정ID.r2.cloudflarestorage.com` 모양

## 3. `.env.public`에 6줄 넣고 재시작

`asmr-block\.env.public`을 메모장으로 열고 맨 아래에 붙여 넣기 (값은 위에서 복사한 것으로):

```
STORAGE_TYPE=s3
R2_ENDPOINT=https://계정ID.r2.cloudflarestorage.com
R2_BUCKET=asmrblock-files
R2_ACCESS_KEY=액세스 키 ID
R2_SECRET_KEY=비밀 액세스 키
R2_PUBLIC_URL=https://files.asmrblock.com
```

저장 → `start-public.bat` 실행(재시작).

- 키는 `.env.public`에만 있어요 (GitHub에 안 올라감). 남에게 보여 주지 마세요
- 값이 하나라도 비어 있으면 서버가 켜지다 멈추고, 어떤 값이 빠졌는지 알려 줘요

## 4. 잘 됐는지 보기

1. 관리자 페이지 → **통계** → 디스크 아래 **"파일 저장소: 클라우드 (버킷 asmrblock-files) · 옛 파일 옮기기 120/120 · 끝"**
   - 켜진 뒤 뒤에서 옛 파일을 옮겨요 (파일이 많으면 몇 분). **옮기는 동안에도 사람들은 그대로 들을 수 있어요** (아직 안 옮긴 파일은 PC에서 재생)
   - "실패"가 보이면 재시작하면 남은 것만 다시 옮겨요
2. 상점에서 블록을 재생해 보기 → 잘 나오면 끝. (주소가 `https://files.asmrblock.com/...`)

## 어떻게 돌아가나요 (궁금하면)

- 새로 올린 소리·사진·영상·완성본 → **R2에 바로** 저장. PC에는 서버가 소리를 합칠 때 쓰는 블록 소리만 잠깐 받아 두고, 3일 안 쓰면 지워요
- DB에는 파일 "이름"만 있어서 주소가 저절로 R2로 바뀌어요 (앱 업데이트 필요 없음)
- 옛 파일은 PC에 그대로 남아요 (지우지 않음). R2로 다 옮긴 게 확인되면 나중에 지워도 돼요
- **백업**: R2 파일은 Cloudflare가 여러 곳에 나눠 안전하게 보관해요. DB(가입자·조합) 백업은 지금처럼 PC `backups` 폴더에 매일

## 되돌리기

`.env.public`에서 `STORAGE_TYPE=s3` 줄 앞에 `#`을 붙이고 재시작하면 다시 PC 디스크를 써요.
⚠ 다만 R2로 바꾼 뒤에 새로 올린 파일은 PC에 없어서 안 보여요 — 되돌릴 일이 생기면 먼저 물어봐 주세요.
