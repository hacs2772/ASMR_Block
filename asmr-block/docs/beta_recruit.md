## 1. ASMR 커뮤니티·카페 (긴 글)

**제목**: 좋아하는 트리거만 골라서 내 ASMR을 직접 쌓는 사이트를 만들었어요 (베타, 무료)

안녕하세요. ASMR을 매일 듣고 자는 사람인데, 영상마다 좋아하는 부분이 조금씩만 있어서 늘 아쉬웠어요.
탭핑은 좋은데 중간에 말소리가 나오거나, 빗소리는 좋은데 너무 짧거나요.

그래서 **소리 하나를 블록 하나로 만들어서, 좋아하는 트리거 블록만 골라 레고처럼 이어 붙이는** 사이트를 만들었어요.

🔗 https://asmrblock.com

**이렇게 써요**
1. 블록 상점에서 팅글 오는 소리(탭핑·바스락·귓속말·빗소리…)를 골라 "블록 담기"
2. 조합 만들기에서 담은 블록을 끌어서 쌓기 (둘째 줄 "레이어드"에 빗소리를 깔 수도 있어요)
3. 얼마나 들을지(30분~8시간) 고르고 저장하면 끊김 없는 한 곡으로 만들어져요

**잠들기 전에 쓰기 좋게**
- 정한 시간이 되면 소리가 스르르 작아지면서 꺼져요 (잠들기 타이머)
- 휴대폰에서 "홈 화면에 추가"하면 앱처럼 열리고, 화면을 꺼도 계속 들려요
- 다른 사람이 쌓은 조합을 듣고 마음에 들면 한 번에 담을 수도 있어요

**베타라서**
- 전부 무료예요. 가입 없이 "베타로 바로 시작"으로 써 볼 수 있어요
- 아직 소리 블록이 많지 않아요. 직접 녹음한 ASMR을 블록으로 올려 주실 분도 찾고 있어요 (블록 판매 메뉴)
- 불편한 점, 있었으면 하는 트리거를 오른쪽 아래 "의견" 버튼으로 남겨 주시면 하나하나 읽어요

혼자 만들고 있어서 부족한 데가 많을 거예요. 한 번 써 보시고 솔직하게 말씀해 주시면 정말 큰 도움이 돼요. 고맙습니다!

## 자주 받을 질문 (답장용)

- **무료예요?** 베타 기간에는 전부 무료예요. 나중에 유료 블록이 생겨도 무료 블록은 계속 무료로 담을 수 있어요
- **가입해야 해요?** "베타로 바로 시작"을 누르면 가입 없이 써요. 같은 휴대폰·브라우저에서 다시 누르면 같은 계정이에요
- **앱은 없어요?** 지금은 웹사이트예요. 휴대폰에서 "홈 화면에 추가"하면 앱처럼 열려요 (안드로이드 앱은 베타 링크로 따로 드릴 수 있어요)

- **개인정보는요?** https://asmrblock.com/privacy 에 쉬운 말로 적어 뒀어요. 베타 손님 계정은 이메일을 받지 않아요
